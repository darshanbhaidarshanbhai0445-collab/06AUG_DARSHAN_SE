1. Five IT Job Roles
    1. Software Developer: Designs, writes, and maintains computer programs.
    2. Web Developer: Creates and manages websites and web applications.
    3. Data Analyst: Studies data and prepares useful reports.
    4. Network Engineer: Installs, manages, and troubleshoots computer networks.
    5. Software Tester: Tests software to find bugs and check its quality.
  2. Product and Service Companies
    1. Product Companies:
      1. Microsoft: Develops products such as Windows, Microsoft 365, and Azure.
      2. Google: Develops products such as Google Search, Gmail, and Android.
      3. Apple: Develops products such as the iPhone, iOS, and macOS.
    2. Service Companies:
      1. TCS: Provides software development and IT consulting services.
      2. Infosys: Provides cloud, software, and digital transformation services.
      3. Wipro: Provides cybersecurity, technology support, and business solutions.
  3. Full Forms and Uses
    1. GitHub: A platform used to store, manage, and share source code.
    2. Slack: A communication platform used by teams for messages and collaboration.
    3. Jira: A project management tool used to track tasks and software bugs.
    4. IDE: Integrated Development Environment; used to write, run, and debug programs.
    5. API: Application Programming Interface; allows different software applications to communicate.
  4. Five Programming Languages
    1. Python: Used for artificial intelligence, data science, and automation.
    2. Java: Used for Android applications and enterprise software.
    3. JavaScript: Used to create interactive websites and web applications.
    4. C++: Used for games, operating systems, and high-performance software.
    5. SQL: Used to store, search, and manage database information.
  5. Difference Between a Developer and a Tester
    1. A developer writes and maintains code to build software applications.
    2. A tester checks the software to find bugs and confirm that it works correctly.
